# Surfer Character 3D Model

This folder contains a generated, stylized 3D model based on the provided character turnaround.

## Files
- `surfer_character.obj` - mesh geometry.
- `surfer_character.mtl` - material definitions.
- `surfer_character_preview.svg` - quick viewport render preview.

## Regenerate
```bash
python3 tools/generate_character_model.py
python3 tools/render_character_preview.py
```
